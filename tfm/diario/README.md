# Diario de trabajo — TFM

Bitácora de las sesiones de trabajo (David + Claude). No forma parte del build LaTeX:
son notas en Markdown, materia prima para redactar los capítulos y para justificar
decisiones de diseño cuando toque defenderlas.

## Convención

*   Un fichero por día: `YYYY-MM-DD.md`.
*   Se escribe **al cierre de la sesión** (o al final del día si hubo varias).
*   Recoge **ideas y decisiones**, no un log de comandos. Si una idea se descartó,
    se anota igualmente con el motivo — el descarte es material de tesis.

## Plantilla

```markdown
# YYYY-MM-DD

**Rama:** <git branch>  ·  **Sesiones:** <nº>

## Ideas
Lo que se pensó: hipótesis, alternativas consideradas, intuiciones.

## Decisiones
Lo que se cerró, y **por qué**. Una línea por decisión.

## Trabajo adelantado
Lo que quedó hecho: código, experimentos, texto. Con commits o rutas.

## Resultados / números
Métricas medidas ese día, con el experimento del que salen.

## Descartado
Lo que se probó y no siguió, con el motivo.

## Siguiente
Lo que queda abierto para la próxima sesión.
```
