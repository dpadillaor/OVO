# Project Root Directory Summary: OVO

This document summarizes the top-level directories of the OVO (Open-Vocabulary Online Semantic Mapping) project.

## Key Directories:
*   `ovo/`: Contains the core logic and entities of the OVO system, including semantic instance management, SLAM wrappers, and utility functions.
*   `scripts/`: Holds various utility scripts for running experiments, data preprocessing, and baseline generation.
*   `documentacion/`: Stores project documentation, decision logs, and feature-specific notes.
*   `data/`: Manages project data, including input datasets, configuration files, and output results.
*   `thirdParty/`: Houses external libraries and modules integrated into the project, such as ORB-SLAM3 and Segment Anything 2.
*   `run_eval.py`: The main entry point for running OVO experiments and evaluations.
*   `GEMINI.md`: Documentation for the Gemini CLI and project context.
*   `ReadMe.md`: General project overview and installation instructions.

## Purpose:
The root directory serves as the main entry point for the OVO project, containing all major components, scripts, data, and documentation. Understanding its structure is key to navigating the entire codebase.
