# Fusion Strategy Refactor (Task 11)

This task consists of refactoring the instance fusion logic in OVO using the Strategy pattern, enabling dynamic selection of different fusion algorithms (CLIP, DINO, PE, geometric, etc.) in a decoupled and extensible way.

## Task files
- `strategy.md`: Describes the architecture and the strategy to be implemented.
- `tests.md`: Summarizes the proposed TDD tests to validate the Strategy pattern infrastructure.

See both files for implementation and validation details.
