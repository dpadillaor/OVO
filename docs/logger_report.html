OVO Logger — Variables Reference

All variables recorded by ovo/entities/logger.py across a single scene run.

Timing — Per-frame semantic pipeline

Logged inside ovo.py every segment_every frames (default 10). One value per qualifying frame.
Key / FileFormatBadgeDescription
t_sam
logger/t_sam.log		 float (seconds) per-frame Time for SAM segmentation (mask generation). One entry per segmented frame.
t_obj
logger/t_obj.log		 float (seconds) per-frame Time for object tracking / instance matching against existing 3D map.
t_clip
logger/t_clip.log		 float (seconds) per-frame Time for CLIP feature extraction per keyframe (processed from queue, may lag behind segment step).
t_up
logger/t_up.log		 float (seconds) per-frame Time to update instance CLIP descriptors after extraction.
t_seg
logger/t_seg.log		 float (seconds) per-frame Reserved for segmentation time (currently not populated — always empty).

Counts — Per-frame

Key / FileFormatBadgeDescription
frame_id
logger/frame_id.log		 int per-frame Frame index. Logged twice per qualifying frame: once in the segment step (with t_sam/t_obj), once in the CLIP step (with t_clip/t_up). Total entries ≈ 2× segment frames.
With segment_every=10, frame 2000 → ~400 entries total.
n_matches
logger/n_matches.log		 int per-frame Number of 3D points matched to 2D pixels in the current frame (depth-based deduplication). High values indicate dense overlap with existing map.
n_obj
(not written)		 list[int] per-frame Number of new instances created per frame. Stored in memory but skipped by write_stats — never persisted to disk.

Timing — Semantic fusion (end-of-sequence)

Logged once at end of sequence when map_updated = True triggers ovo.update_map(). Each file contains exactly 1 value. wc -l reports 0 because '\n'.join([val]) produces no trailing newline — use cat to read.
Key / FileFormatBadgeDescription
t_fusion
logger/t_fusion.log		 float (seconds) once Total time for the full fusion pass (precompute + all criterion evaluations + descriptor update).
t_loop_closure_refusion
logger/t_loop_closure_refusion.log		 float (seconds) once Wall-clock time for the entire map update step (includes fusion + SLAM map access + post-processing). Slightly larger than t_fusion.
t_precompute_fusion
logger/t_precompute_fusion.log		 float (seconds) once · dynamic Time to extract point clouds and centroids for all alive instances before pairwise evaluation.
t_descriptor_update
logger/t_descriptor_update.log		 float (seconds) once · dynamic Time to re-aggregate descriptors (CLIP features) of surviving instances after merges.

Timing — Per fusion criterion

Accumulated time spent inside each criterion across all evaluated pairs. One value per file (end-of-sequence). Criterion chain default: cooccurrence → centroid → cos_sim → overlap. Early-exit means later criteria are only timed for pairs that passed earlier ones.
Key / FileFormatBadgeDescription
t_crit_cooccurrence
logger/t_crit_cooccurrence.log		 float (seconds) once Total time in cooccurrence veto. Runs on all pairs. Vetoes pairs sharing > N keyframes (they are different objects seen together).
t_crit_centroid
logger/t_crit_centroid.log		 float (seconds) once Total time in centroid distance criterion. Rejects pairs with centroid distance > th_centroid (default 1.5 m).
t_crit_aabb
logger/t_crit_aabb.log		 float (seconds) once Total time in AABB distance criterion. Only active if aabb is in fusion_criteria. Not in default chain — file is empty in standard runs.
t_crit_cos_sim
logger/t_crit_cos_sim.log		 float (seconds) once Total time in cosine similarity criterion. Compares CLIP (or other) feature vectors. Rejects if similarity < th_cossim (default 0.81).
t_crit_overlap
logger/t_crit_overlap.log		 float (seconds) once · dynamic Total time in point-overlap criterion. Most expensive criterion — computes 3D point cloud overlap ratio. Accepts/rejects based on th_points (default 0.1).
t_crit_p_dist
logger/t_crit_p_dist.log		 float (seconds) once Legacy key (pre-declared). Equivalent to t_crit_overlap in older code. Always empty in current runs.

Counts — Fusion statistics

Key / FileFormatBadgeDescription
n_instances_alive
logger/n_instances_alive.log		 int once · dynamic Number of active 3D instances at the time fusion runs (before any merges).
n_pairs_evaluated
logger/n_pairs_evaluated.log		 int once · dynamic Total number of instance pairs evaluated by the fusion strategy (brute-force O(n²)/2).
sc_cooccurrence
logger/sc_cooccurrence.log		 int once · dynamic Pairs short-circuited (decided) by the cooccurrence criterion (either accepted or rejected early).
sc_centroid
logger/sc_centroid.log		 int once · dynamic Pairs short-circuited by centroid distance. This is typically the largest count — most pairs are too far apart.
sc_cos_sim
logger/sc_cos_sim.log		 int once · dynamic Pairs short-circuited by cosine similarity (semantically dissimilar pairs rejected before expensive overlap check).
sc_overlap
logger/sc_overlap.log		 int once · dynamic Pairs decided by point-cloud overlap (final criterion — both accepted merges and rejections). sc_cooccurrence + sc_centroid + sc_cos_sim + sc_overlap = n_pairs_evaluated.

Fusion decisions — fusion_decisions.csv

Appended incrementally to disk during each fusion event. Survives crashes. One row per evaluated pair that reached a decision.
ColumnFormatBadgeDescription
frame_id int CSV Frame at which this fusion event was triggered.
result ACCEPTED | REJECTED CSV Whether the pair was merged into one instance.
i1 int CSV ID of first instance in the pair.
i2 int CSV ID of second instance. On ACCEPTED, i2 is merged into i1 and deleted.
reason string: criterion name CSV Which criterion short-circuited this pair (e.g. centroid, cooccurrence, overlap).
centroid_dist float (metres) | empty CSV Euclidean distance between instance centroids. Empty if pair was rejected before centroid was computed.
aabb_dist float (metres) | empty CSV AABB-to-AABB distance. Only populated if aabb criterion is active.
cos_sim float [−1, 1] | empty CSV Cosine similarity between instance feature vectors. Empty if pair was rejected before reaching cos_sim criterion.
p_dist float [0, 1] | empty CSV Point-cloud overlap ratio computed by the overlap criterion. Empty if pair was rejected earlier.
shared_kfs int | empty CSV Number of keyframes in which both instances co-occurred. Used by cooccurrence veto. Empty if cooccurrence criterion is not active.

File format notes

DetailExplanation
.log files Plain text, one value per line. Written by write_stats() at end of run using '\n'.join([...]) — no trailing newline. wc -l will report 0 for single-entry files; use cat or check file size.
dynamic keys Keys marked dynamic are created in self.stats at runtime when first logged. They exist in output only if the relevant code path ran (e.g. fusion must have triggered for sc_* and t_crit_overlap to appear).
fusion_decisions.csv Appended per fusion event (not buffered). Survives process crash. Initialized (truncated) at Logger construction, so re-running the same output folder overwrites it.
n_obj Intentionally skipped by write_stats — it contains a list-of-lists (one list per frame). Not currently persisted to disk.
